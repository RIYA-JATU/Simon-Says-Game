# Simon Says Game

## Description
This is a learning-based project where I tried to replicate the classic **Simon Says Game**
using **HTML, CSS, and JavaScript**.

The main purpose of this project was to practice **JavaScript DOM Manipulation**, event handling,
and game logic by building an interactive UI.

## Features
- Generates a random color sequence
- User has to repeat the same sequence
- Level increases on correct input
- Game resets on wrong input

## Technologies Used
- HTML
- CSS
- JavaScript (DOM Manipulation)

## What I Learned
- DOM selection and manipulation
- Handling user events (clicks, keypress)
- Using arrays and functions for game logic
- Updating UI dynamically using JavaScript

## How to Play
1. Open `index.html` in a browser
2. Start the game
3. Watch the color sequence
4. Repeat the sequence by clicking the buttons
5. Game ends if the sequence is wrong
